# Splashes Swim School

This project is a static multi-page website for Splashes Swim School, a swim instruction and youth aquatic program brand. It includes the home page, program pages, contact and registration sections, and a responsive layout built with HTML, CSS, and JavaScript.

## Project overview

The site is designed to showcase:
- swim lessons and class offerings
- lesson locations and programs
- adult swimming programs
- registration and contact information
- brand visuals, awards, and promotional sections

## Pages included

- `index.html` - homepage
- `about.html` - about the school
- `lessons.html` - swim lesson information
- `programs.html` - swim programs
- `adult-programs.html` - adult-specific offerings
- `locations.html` - location details
- `contact.html` - contact information
- `register.html` - registration/sign-in page

## Files

- `style.css` - site styling and layout
- `script.js` - interactive behavior, including navigation toggling
- `images/` - logos, graphics, and page photography
- `Fonts/` - custom typography assets
- `Graphics/` and `Page Mockups/` - additional design assets

## How to view locally

Because this is a static website, you can open the project in a browser without installing a framework or server.

### Option 1
Open `index.html` directly in your browser.

### Option 2
Run a local web server from the project folder, for example:

```bash
cd /Users/zeel/Documents/Westcliff/WEB801/Project1-Zeel-Sang
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
